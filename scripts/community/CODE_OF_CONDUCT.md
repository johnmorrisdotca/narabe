# Code of conduct

Every johnmorrisdotca package follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, welcome newcomers, and keep criticism
about the work rather than the person. Harassment of any kind is not accepted.

Report unacceptable behaviour to the maintainer at john@johnmorris.ca. Every
report is read and kept confidential.
